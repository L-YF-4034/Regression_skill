01｜分析目標與適用範圍

guided-linear-regression是一套以R執行的互動式迴歸分析skill，協助使用者依研究問題選定變數、確認模型，再進行估計與診斷。分析結果以繁體中文解釋，流程結束後整理為Quarto QMD與PDF，保留可重現的程式碼、圖表及方法依據。

適用資料以CSV為主，一個row代表一筆觀測，一個column代表一個變數。反應變數Y為單一連續數值變數，解釋變數X可包含數值及已確認參考組的類別變數。二元或計數反應、重複測量與群聚資料，應另外評估適合的模型。

核心原則：先看資料，再確認選擇，最後整理成果。

先展示所有數值變數的兩兩散佈圖，再詢問Y與X。模型、階數、配適與診斷逐步確認；使用者尚未回答時不代為決定，診斷標記也不直接作為刪除資料的理由。

使用者決定研究方向

確認變數意義、單位、研究目的、模型設定與各階段是否執行。變數角色依研究問題決定，不以相關係數自動推斷方向。

R程式負責計算

以固定函數產生VIF、係數、檢定及圖形，再根據實際輸出撰寫解釋。將分析設定與計算程序保存於可重現的報告中。

02｜完整分析流程

綠色框為需要停下等待回答的確認點。若不繼續配適，則以已完成的探索與設計診斷結束；略過殘差或轉換時，仍可確認是否進行離群分析。互動期間呈現結果與圖形，最終報告於流程結束後製作。

03｜從探索圖到模型設定

先探索資料，再指定Y與X

分析開始時檢查樣本數、欄位型態、缺失及特殊編碼，並展示所有可繪圖數值變數的兩兩散佈圖；變數較多時分頁呈現。類別與文字欄位另列說明，採合適圖形，不強制轉為數值。展示後再詢問反應變數與解釋變數。

以VIF檢視模型設計

選定角色後，先列出X、Y、一次候選公式及研究目的，再提供VIF與tolerance。VIF以X設計矩陣的輔助迴歸計算，此時尚不估計Y的模型。

設定呈現範例

X：Girth；Y：Volume。若使用一次項，模型類型為簡單線性迴歸：

Volumeᵢ = β₀ + β₁ Girthᵢ + εᵢ

此模型用來分析Girth與Volume的線性關係。只有這一個數值X時，VIF按定義為1；這不表示誤差獨立，也不代表一次模型必然適合。

VIF範圍建議的解讀
1至小於5未見強烈共線性訊號，仍需考量研究設計。
5至小於10留意共線性，檢查變數重複、尺度與模型設定。
10以上共線性偏高，進一步核查設計及中心化。
Inf或秩不足檢查完全或近完全依賴，修正後再配適。

上述範圍為經驗提示，不是顯著性檢定。腳本提供column層級VIF，將factor dummy與多項式冪次分開列示，並非term層級GVIF；不依門檻自動刪除變數。

依圖形提出模型候選

資料型態與趨勢模型候選確認內容
全部採一次項，單一原始X簡單線性迴歸變數、公式及是否配適。
全部採一次項，多個原始X複迴歸控制變數、參考組及是否配適。
平滑彎曲、U形或倒U形可考慮二階多項式：X、X²哪些X需要次方項、採用幾階及是否中心化。
明顯S形或較複雜趨勢，且資料充分有理由時考慮三階：X、X²、X³階數是否有圖形與研究背景支持，是否保留較簡單模型。

圖形支持的是候選建議，不能直接視為最佳階數。多項式保留所有低階項，不因單一離群外觀升階，也不自動產生交互作用。

Yᵢ = β₀ + β₁(Xᵢ−c) + β₂(Xᵢ−c)² + εᵢ

中心化以固定常數c表達，通常建議使用分析資料的X平均數，並先取得確認。選定階數與中心值後，重新呈現公式及VIF，再詢問是否配適。中心化可改善部分非本質共線性，但不保證VIF必然降低。

估計結果與配適圖

確認後以lm()配適，呈現summary(fit)、係數95%信賴區間、整體F、R²、調整R²及殘差標準差。單一數值X以原始點與配適直線／曲線比較；多個X另畫實際值對配適值，以及固定其他X後的條件線／曲線。

04｜殘差、轉換與影響診斷

殘差分析

取得同意後，檢視殘差對配適值、各X、Q-Q及scale-location圖，並執行Shapiro–Wilk、學生化Breusch–Pagan及雙尾Durbin–Watson。檢定結果與圖形共同解讀，未拒絕假設不等於證明假設成立。

Durbin–Watson按目前分析資料的row順序執行。若未確認該順序具有時間或採樣意義，需說明其結果依賴排列方式，不能據此證明誤差獨立。

Box–Cox轉換

若殘差顯示需要評估轉換，先取得探索同意，再呈現Box–Cox plot、lambda估計值與95%profile信賴區間。使用者可指定lambda；同意轉換且未另指定時，使用估計值。報告分開記錄估計值、區間及實際使用值。

轉換要求Y為正值；完成後重新配適與診斷，沿用X的階數及固定中心值。轉換不保證消除觀測相依，不同反應尺度的R²或未校正AIC也不直接作優劣比較。

離群與影響樣本

最後另行確認是否計算槓桿、內外學生化殘差、Cook’s distance、DFFITS及DFBETAS。計算涵蓋全部分析樣本，但只輸出至少一項門檻被標記者，包含原始row ID、診斷值與觸發原因；DFBETAS亦只列這些樣本。

沒有任何標記時，明確顯示「沒有被所用門檻標記的離群值或影響樣本」。高槓桿、反應離群與影響點分開解釋，不自動刪除資料。

05｜分析結束與成果報告

互動期間保存設定、結果與確認紀錄。流程走完，或使用者明確不繼續而結束時，先告知「此次分析結束」，接著生成QMD並編譯PDF，不再為報告製作多問一次。

最終報告依實際成功完成的階段選取內容。未執行、拒絕、失敗或中止的部分，其標題、程式碼、圖形與解釋均不納入；不以單純關閉執行的方式留下空白章節。

逐段呈現分析依據

程式碼 → 實際結果／圖 → 中文解釋

每段解釋緊接相應輸出，讓讀者能理解數字、圖形與結論的關係。

交付可重現的成果

包含QMD、編譯且檢視過的PDF，以及必要的CSV與R程式。若編譯失敗，保留來源檔並如實說明。

QMD模板保留階段邊界，報告生成器依completed_stages實體選取章節並重新編排Code編號。授權與成功完成是兩個不同狀態：已同意但未成功執行的步驟，不視為已完成。

報告製作的執行方式
source("<skill路徑>/scripts/finalize_report.R", encoding="UTF-8")
write_final_report(
  template="<skill路徑>/assets/report.qmd",
  output="report/analysis.qmd",
  params=analysis_params,
  completed_stages=completed_stages,
  analysis_finished=TRUE,

例如只完成探索、VIF與模型配適時，成功階段清單為c("exploration","vif","fit")。報告便保留這些內容及重現資訊，不包含殘差、轉換或離群章節。

07｜可重現性與方法依據

固定種子20261020、資料MD5、row順序、缺失處理、factor levels、參考組、模型公式、多項式階數、中心值、VIF基底、alpha及lambda設定。另保存R與套件版本、Quarto版本及各階段確認紀錄；跨機重現可使用renv鎖定套件。

OLS本身沒有隨機性，數值一致仍需相同資料、設定與軟體環境。PDF的字型、時間與metadata可能不同，因此不保證檔案位元組相同。預設採alpha＝0.05、雙尾檢定與95%信賴區間；所有數字取自實際R輸出。

主要方法參考Program_1.pdf、Program_2.pdf，以及Montgomery、Peck與Vining（2012）的Introduction to Linear Regression Analysis第5版。VIF、多項式基底與相關補充方法，另參考NIST VIF說明、R多項式文件及car VIF／GVIF文件；來源對照與教材勘誤整理於方法文件。
