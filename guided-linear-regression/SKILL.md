# 迴歸分析流程：簡單、複迴歸與多項式迴歸

本 skill 帶使用者從原始資料走到模型估計與診斷。**先畫圖，再詢問；每個確認點都必須停止，等待明確回答。**
「請幫我分析」不代表已同意後續所有步驟。使用者尚未回答時，不得代替使用者選擇「是」。

**所有分析數字必須來自 `scripts/regression.R` 的 R 函數或已審查的報告模板輸出。**
不得心算、捏造、改用 Python 計算，或臨時自行補算模板與函數沒有提供的統計量。
自行撰寫的呼叫程式限於讀檔、資料型態設定、已確認的前處理、呼叫函數及保存結果。
缺少必要功能時，先明示限制；需擴充時更新腳本與方法文件並驗證，不以未審查程式繞過流程。

## 範圍

| 分析項目 | 本 skill 函數或模板 | 主要 R 工具 |
|---|---|---|
| 資料檢查、摘要與探索圖 | `assets/report.qmd` 的探索區塊 | `summary()`、`pairs()`、`is.na()` |
| 選定X／Y後的設計診斷 | `vif_design()` | 設計矩陣與輔助迴歸VIF；不配適Y |
| 簡單／複迴歸／多項式迴歸 | `model_spec()`、`fit_model()` | `lm()`、完整低階項與固定中心值 |
| 係數、檢定與配適圖 | `fit_output()` | `summary()`、`confint()`、`predict()` |
| 殘差分析 | `diagnostics()` | Q-Q、殘差圖、Shapiro-Wilk、Breusch-Pagan、Durbin-Watson（記錄排序意義） |
| Box-Cox 圖、估計與指定lambda轉換 | `boxcox_profile()`、`transform_model()` | `MASS::boxcox()`、`lm()` |
| 離群值與影響點檢測 | `influence_output()` | `hatvalues()`、`rstandard()`、`rstudent()`、Cook、DFFITS、DFBETAS |

主要處理 CSV 的一筆觀測一個 row 資料，反應變數為連續數值。
類別解釋變數先設為 factor 並確認參考組。ID、姓名、自由文字不自動當解釋變數。
二元反應、計數反應、重複測量或具群聚結構時，說明普通線性迴歸的限制，先確認適用模型，不直接套用。
不自動進行逐步選模、交互作用搜尋、資料平移或刪除離群點。

## 第 1 階段：探索資料與畫圖（到這裡一定要停下來）

1. 讀取檔案，檢查每個 row 的觀測單位、欄位與資料說明。**此時不預設或要求使用者先指定 Y、X；先呈現所有變數的兩兩散佈圖，再詢問變數角色。**
2. 檢查樣本數、欄位型態、遺失值、無限值、常數欄及 ID。遇到特殊遺失碼或需刪除 row 時，先確認處理規則，保留原始 row ID。
3. 對**全部可繪圖的數值變數**畫出兩兩散佈圖矩陣，不只畫預選的候選 X、Y。變數很多時分組或分頁，但須涵蓋所有變數配對；不因相關較低而省略。文字／類別欄位不能硬轉數值畫散佈圖，另列欄位表並補充分組圖；ID若以數值儲存可展示，但清楚標記不自動納入模型。說明偏態、曲線、散布範圍與可能異常外觀，但**不做正式離群檢測或刪點**。
4. **先顯示散佈圖，再詢問「哪一個變數作為反應變數（Y）？哪些變數作為解釋變數（X）？」並停止等待。** 同時確認其意義、單位與研究問題，不由圖形或相關係數自行決定方向。反應變數先選一個連續數值變數；角色未確認前，不執行 `lm()`、係數檢定、殘差檢定、Box-Cox 或影響診斷。
5. 本階段只在對話展示摘要與圖，保存分析狀態；不生成最終報告、不編譯PDF，後續approval維持false。
6. 使用者指定Y與X後，先列「已設定X、Y、候選模型類型、模型公式、研究目的」，隨即呼叫`vif_design(..., selection_confirmed=TRUE)`呈現VIF、tolerance與中文建議。這一步依使用者選定角色即獲授權，只對X設計矩陣作輔助迴歸，不提前估計Y的模型或顯著性。未選X不計算。單一數值X的VIF為1，說明沒有其他X可比較，不宣稱證明獨立；多個X按methods解讀，不自動刪除。
7. 以散佈圖及研究機制判斷是否值得提議多項式：近似直線先推薦一次項；平滑彎曲／U形／倒U形可建議二階`X + X²`；有明顯S形或兩次轉折、且有足夠資料支持時，才建議三階`X + X² + X³`。這是候選建議，不是已驗證最佳階數。指出具體變數與次方項；多個X時只對有理由者加次方，不自動產生交互作用。離群外觀不能單獨作為升階依據。
8. **詢問「要採簡單／複迴歸的一次模型，或多項式模型？若採多項式，各X要用幾階？」並停止等待。** 未回答不能自動採二階。一次模型依原始X個數分類；任何X階數大於1均標示多項式迴歸，另外註明單一或多個原始X。保留所有低階項，不因不顯著移除。檢查不同X值數量必須大於階數及殘差自由度足夠，高階不外推。
9. 若選多項式，確認是否使用中心化（預設建議使用），記錄中心值並依最後階數重新計算VIF、列出實際公式與建議；中心化X的符號、係數解讀須明示。最後**詢問「是否依此模型、階數與中心化設定進行迴歸？」並停止等待。** 選定角色／階數僅允許設計VIF，不等於同意配適Y。

使用者回答「否」時保留探索結果並結束，不自行挑另一個模型繼續。

## 第 2 階段：建立模型與呈現結果

只有第 1 階段獲得明確同意後才能進入。

1. 讀 `references/decision-tree.md` 與 `references/methods.md`，確認適用條件、公式與設定。
2. 依已確認的模型及階數配適：全部為一次時，一個原始X採simple linear regression，兩個以上採multiple regression；任何X含高次項則採polynomial regression。`degrees`須以X名稱指定階數，例`c(Girth=2)`，未列者為1。使用固定中心值保留低階項。
   類別變數有多個虛擬變數係數時，另外說明設計矩陣結構，不只根據係數個數分類。
3. 以 `fit_model(..., approved=TRUE, degrees=已確認階數, center=已確認設定, centers=已記錄中心值)` 配適，再呼叫 `fit_output()`。
   秩不足、殘差自由度不足或無效資料時停止說明，不強行估計。
4. 依下列小節呈現：
   - **適用條件與模型**：寫出公式、樣本數、參考組及尚未檢查的假設。
   - **係數估計與檢定**：呈現完整 `summary(fit)`，解釋 Estimate、SE、t、p-value，並提供 `confint(fit)`。
   - **整體配適**：解釋整體 F 檢定、R²、調整 R²及殘差標準差。整體 F 的虛無假設是斜率全為零，不是截距為零。
   - **原始資料與配適結果**：單一數值X畫原始點與依模型預測的直線／多項式曲線；多個X畫 observed versus fitted 及條件配適線／曲線，明示其他 X 固定於何值。
   - **結論**：以研究問題的語言解釋關聯；殘差假設尚未檢查時，標示推論為暫定。
5. 保存分析結果與確認紀錄（最終報告於結束後生成）。
6. **詢問「是否進行下一步殘差分析？」並停止等待。**

使用者回答「否」時跳到第 4 階段的詢問，不先執行離群分析。

## 第 3 階段：殘差分析與 Box-Cox 建議

只有使用者同意殘差分析後，才呼叫 `diagnostics(..., approved=TRUE)`。

### 殘差分析

1. 讀 `references/methods.md` 的殘差段落，依 `references/textbook-methods.md` 撰寫。
2. 檢視殘差對配適值、殘差對各 X、Q-Q 與 scale-location 圖。
   不使用 `plot(fit)` 的 Cook／leverage 面板，避免提前執行最後階段。
3. 執行 Shapiro-Wilk 與學生化 Breusch-Pagan，列出假設、統計量、p-value與結論，並結合圖形解讀。
4. 不論是否確認時間或採樣順序，都執行雙尾 Durbin-Watson。`ordered` 只標記排序意義，不控制是否執行；沒有已確認順序時沿用目前分析資料 row 順序，明示排序依賴，不能將不拒絕一階相關為零寫成證明完全獨立。
5. 依曲線型態、變異數及尾端偏離，提出「建議／暫不建議／證據不足」的 Box-Cox 建議。
   不因單一 p-value 自動轉換，也不宣稱轉換能修復採樣相依。

### Box-Cox（另一次確認）

提出轉換建議後，**詢問「是否執行 Box-Cox 轉換並重新配適？」並停止等待**；使用者拒絕或沒有必要時保留原模型，進入第 4 階段的詢問。

同意後：

1. 確認 Y 全為正值；不符合時停止說明，不任意加常數。
2. 先呼叫 `boxcox_profile(..., approved=TRUE)`，呈現 Box-Cox plot、lambda估計值與95% profile CI（固定網格及端點線性內插近似），此時尚不轉換。展示後詢問「要指定哪個lambda，或使用估計值？」並等待；沒有另指定且已同意轉換時採估計值。再呼叫 `transform_model(..., lambda=指定值或NULL, profile=前述結果, approved=TRUE)` 執行轉換，分開記錄lambda估計值、CI、實際使用值及來源。指定值在CI之外可使用，但須如實註明，不擅自改值。
3. lambda 在搜尋邊界時，依 methods 擴展網格並記錄；不能直接接受邊界結果。
4. 對轉換後模型重新執行 `fit_output()` 與 `diagnostics()`，說明改善與仍有的限制。
5. 不直接以不同反應尺度的 R²或未校正 AIC 比較模型；反轉換不自動等於無偏平均。
6. 保存分析結果與確認紀錄（最終報告於結束後生成），進入第 4 階段的詢問。

## 第 4 階段：離群值與影響點檢測（先詢問，再執行）

**先詢問「是否進行離群值與影響點檢測？」並停止等待。** 回答「是」後才執行本階段，回答「否」則結束。

1. 明示目前診斷的是原模型或使用者已同意採用的轉換後模型。
2. 呼叫 `influence_output(..., approved=TRUE)`，只呈現被至少一項門檻標記的樣本及其原始row ID、診斷值、觸發原因與DFBETAS；沒有則只說「沒有被所用門檻標記的離群值或影響樣本」。
3. 引用 `references/methods.md` 的門檻，說明學生化殘差的 Bonferroni 校正，以及經驗門檻只用於篩檢。
4. 區分高槓桿、反應離群與影響點；被標記不代表資料錯誤，沒有標記也不代表模型已完美。
5. **不得自動刪除。** 需要資料核查或刪點敏感度分析時，另提具體建議取得確認；永遠保留原模型。
6. 更新分析狀態；流程結束時先告知「此次分析結束」，再生成只含已完成內容的QMD並編譯PDF。

## 分析報告：qmd 與 PDF

**報告必須逐段交錯排列「程式碼 → 該段實際輸出／圖表 → 該段中文結果解釋」，再進入下一段程式碼。** 不把所有程式碼集中附錄，也不把解釋集中在最後。每個分析chunk開啟echo與結果顯示；緊接其後用一般文字或echo=false、results=asis的敘述chunk，依本段R物件解釋估計、統計量、p-value、CI或圖形。未授權段落不提供假結果；正式交付須將模板中的圖形解釋提示改為實際檢視後的描述。程式碼用本skill已審查函數與模板，不臨時補算。

- 以 `assets/report.qmd` 作為格式與階段控制模板，依實際資料修改檔名、變數、樣本數檢查與資料說明；模板中的 trees 設定不可直接套用其他資料。
- 建立 `analysis_<資料名稱>.qmd`，同資料夾放原始 CSV、`regression.R` 及報告需要的圖或資源，使用相對路徑。
- 報告包含資料概況、探索圖、確認紀錄、已授權的模型／診斷結果、中文解釋、方法來源與重現資訊。未完成的階段整段排除，不保留其標題、程式碼、圖、解釋或待確認提示。
- 五個 approval 參數（包含新增的 `approve_boxcox_profile`）預設為 `false`；取得對應確認後才更新。拒絕與尚未回答須在紀錄中分開，不能只用布林參數代表兩者。
- 重新編譯只能重現已授權的分析，不得自動同意下一階段；不把 `readline()` 放進編譯程序。
- 使用 `quarto render analysis_<資料名稱>.qmd --to pdf`，完成後實際開啟PDF，檢查中文字型、圖表、程式碼換行與分頁。
- 編譯失敗時保留 qmd 與R輸出，具體說明錯誤；未驗證的PDF不能宣稱已完成。

## 重現性與確認紀錄

1. 每次開始呼叫 `configure()`：固定種子20261020、RNGkind、digits與contrasts。OLS本身無隨機性，不能只靠種子保證一致。
2. 固定資料檔、row次序、欄位型態、缺失規則、factor levels、參考組、公式、多項式階數、中心值、VIF設計基底、alpha及lambda網格。
3. 保存資料MD5、R及套件版本（`sessionInfo()`）、Quarto版本及執行參數。需要跨機重現時使用renv鎖定套件。
4. 保存每個確認點的使用者原回答與執行階段；資料、Y或公式變動後，後續確認失效，返回探索階段。
5. 相同環境與設定下重現數值結果；PDF的時間metadata、字型或版本可能改變位元組，不承諾每份PDF檔案雜湊相同。
6. 功能測試使用另造且固定的模擬資料，不能為測試而提前對使用者尚未授權的資料配適。

## 寫作規則

- 繁體中文、台灣用語；保留必要英文名詞與R函數名稱。
- 表格方向用row／column，避免「行」「列」歧義。
- 預設顯著水準alpha=.05、雙尾檢定、95%信賴區間；使用者指定時依指定設定，不因結果自行調整。
- 檢定依「適用條件→建立假設→檢定統計量→p-value→結論」撰寫；數字直接引用R輸出。
- p≥alpha寫「沒有足夠證據拒絕」，不寫證明常態、同方差或獨立；p<alpha也不表示因果。
- 多元係數須說明控制其他X；R²為樣本內解釋比例，不當作外部預測準確率。
- 本skill保留係數CI與Box-Cox的profile CI；不沿用無母數範例「只寫檢定、不寫信賴區間」的限制。
- 表格用Markdown語法，公式用 `$...$` 或 `$$...$$`；圖表標明變數、單位及必要條件。
- 方法依三份指定PDF與 `references/methods.md` 的來源對照／勘誤撰寫；不要照抄教材誤植。


## VIF與模型設定的呈現範例

已設定X：Girth；Y：Volume。一次候選為簡單線性迴歸：
$$Volume_i=\beta_0+\beta_1Girth_i+\varepsilon_i.$$
用來分析Girth與Volume的線性關係。以`vif_design()`的實際輸出呈現VIF；若只有這一個數值X，其值按定義為1。建議寫「沒有其他解釋變數可造成變數間共線性；VIF不評估曲線、誤差獨立或因果」。如果散佈圖彎曲，可另外推薦二階模型並先詢問要用幾階，不能先配適後才詢問。

多項式的Box-Cox後續轉換僅改變Y，沿用相同X階數、中心值與設計。若要改階數，回到模型確認與VIF步驟。原X相同不代表多項式階數已確認。


模型設定確認紀錄：QMD另以`model_confirmed: false`記錄模型類型、各X階數及中心化是否已確認，只有確認後才設true；`approve_fit`須同時滿足selection_confirmed與model_confirmed。`research_goal`保存使用者的研究目的。角色確認後改階數時不沿用一次模型的虛構中心值；僅保存真正多項式項的中心值。最終設計須保留至少2個殘差自由度。


## 最終輸出規則（取代任何較早的分階段報告指示）

1. 離群與影響分析仍對全部分析樣本計算，但只print至少一項門檻為true的樣本。合併列原始row ID、數值及flag_reason，DFBETAS也只列這些樣本；不print完整無問題樣本表。若沒有任何標記，只說「沒有被所用門檻標記的離群值或影響樣本」。不自動刪點。
2. 互動期間只展示當階段結果與圖、保存狀態，不逐階段生成最終QMD或編譯PDF。走完流程，或使用者明確拒絕後續而結束時，先在對話告知「此次分析結束」，接著直接產生報告，不再為生成報告多問一次。
3. 以實際成功完成的completed_stages清單選章節，不把approval=true當作已完成。尚未回答時仍等待，不能自行宣告結束；失敗／中止／拒絕／未執行部分不放入PDF，亦不保留其標題、程式碼或待確認提示。內部確認紀錄可保留，不作空白章節。
4. `scripts/finalize_report.R`提供`write_final_report()`：傳入模板、輸出qmd路徑、當次參數、completed_stages及analysis_finished=TRUE；預設直接呼叫Quarto編譯PDF。analysis_finished未確認時拒絕生成。`render=FALSE`僅供開發／檢查；正常交付需編譯且檢視PDF，失敗據實回報。
5. 最終QMD及PDF仍為每段「程式碼→實際結果／圖→該段中文解釋」。生成器實體移除未完成階段，並重新編排Code編號；不能只以eval=false隱藏執行而留下空章節。
