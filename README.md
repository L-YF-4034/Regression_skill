# 互動式迴歸分析 Skill

`guided-linear-regression` 以 R 為計算工具，協助使用者從資料探索、變數設定與模型選擇，進行至估計、診斷及報告製作。支援簡單線性迴歸、複迴歸與多項式迴歸，並以繁體中文說明結果。

分析採逐階段確認：先展示資料圖形，再由使用者指定反應變數與解釋變數；完成模型設定後，分別確認是否進行配適、殘差分析、Box–Cox 轉換及離群值檢測。流程結束時，告知「此次分析結束」，再將已成功完成的內容整理成 Quarto `.qmd` 與 PDF 報告。

## 適用資料與分析範圍

資料以 CSV 為主，一個 row 代表一筆觀測，一個 column 代表一個變數。反應變數 Y 為單一連續數值變數；解釋變數 X 可包含數值變數，以及已確認參考組的類別變數。

提供欄位意義、測量單位、特殊遺失碼與採樣設計，有助於正確解讀。識別碼不自動納入模型，遺失值處理及資料刪除需先確認。二元或計數反應、重複測量及群聚資料，應另外評估適合的模型。

| 分析項目 | 內容 |
|---|---|
| 資料探索 | 欄位檢查、摘要、所有數值變數的兩兩散佈圖 |
| 設計診斷 | 選定 X、Y 後提供 VIF、tolerance 與建議 |
| 模型估計 | 簡單線性迴歸、複迴歸及已確認階數的多項式迴歸 |
| 配適呈現 | 係數與檢定、95%信賴區間、整體配適指標及配適線／曲線 |
| 殘差診斷 | 殘差圖、Q-Q圖、Shapiro–Wilk、Breusch–Pagan及Durbin–Watson |
| 反應變數轉換 | Box–Cox圖、lambda估計、95%信賴區間及指定lambda轉換 |
| 離群與影響分析 | 槓桿、內外學生化殘差、Cook’s distance、DFFITS及DFBETAS |
| 報告製作 | 流程結束後生成僅含已完成分析的QMD，再編譯PDF |

## 使用方式

保留完整的 `guided-linear-regression` 資料夾，讓工具可以同時讀取主規則、方法文件、R程式與報告模板。可在支援skill的工具中選取名稱，或提供 `SKILL.md` 的完整路徑，並附上CSV及資料說明。

建議的起始指令：

> 請使用 guided-linear-regression 分析這份CSV。先呈現所有數值變數的兩兩散佈圖，再詢問我Y與X。選定變數後提供VIF與模型建議，各階段確認後才繼續，最後生成QMD與PDF報告。

如需安裝，將整個資料夾放入所用工具支援的skill目錄；資料夾內應直接包含 `SKILL.md`，不重複包覆同名資料夾。安裝位置與載入方式依工具而定。

## 分析流程

### 1. 探索資料與指定變數

先檢查資料品質，展示所有可繪圖數值變數的兩兩散佈圖；變數較多時分頁呈現。類別與文字欄位另列說明，採用適合其型態的圖形，不強制轉為數值。

圖形呈現後，詢問哪個是反應變數Y、哪些是解釋變數X，並等待回答。變數角色依研究問題決定，不以相關係數自動判定方向。

### 2. 檢視VIF與確認模型

選定X與Y後，列出角色、一次候選公式及研究目的，計算X設計矩陣的VIF。此時只進行X的輔助迴歸，不提前估計Y的模型。

單一數值X的VIF按定義為1；多個設計columns可參考下列經驗範圍：

| VIF | 解讀與建議 |
|---|---|
| 1至小於5 | 未見強烈VIF共線性訊號，仍需考量研究設計 |
| 5至小於10 | 留意共線性，檢查變數重複、尺度及模型設定 |
| 10以上 | 共線性偏高，進一步核查設計與中心化設定 |
| Inf或設計秩不足 | 核查完全或近完全依賴，修正後再配適 |

這些範圍不是顯著性檢定，也不作為自動刪除變數的依據。腳本提供column層級VIF，類別變數的dummy及多項式冪次分別列示，不能解讀成整個term的GVIF。

全部使用一次項時，一個原始X採簡單線性迴歸，兩個以上採複迴歸。若散佈圖呈平滑彎曲，可建議二階；具明顯S形或更複雜趨勢，且資料充分時，才考慮三階。建議需指出變數與具體次方項，並詢問使用者採用幾階。

多項式保留所有低階項，預設建議中心化並記錄固定中心值。確認階數及中心化後，重新呈現公式與VIF，再詢問是否配適。選定變數或階數本身不等於已同意配適。

### 3. 估計模型與呈現配適

取得同意後，以 `lm()` 配適，呈現 `summary(fit)`、係數95%信賴區間、整體F檢定、R²、調整R²及殘差標準差。

單一數值X使用原始資料與配適直線／曲線比較；多個X另呈現實際值對配適值，以及固定其他X後的條件配適線／曲線。結果以研究單位解釋，並明示多項式階數、中心值與類別參考組。

### 4. 診斷殘差與評估轉換

另行確認後，呈現殘差圖與Q-Q圖，執行Shapiro–Wilk、學生化Breusch–Pagan及雙尾Durbin–Watson。

Durbin–Watson按目前分析資料的row順序執行。若未確認為時間或採樣次序，說明其結果依賴排列方式，不能據此證明誤差獨立。所有檢定皆搭配圖形解讀，不把未拒絕假設寫成證明假設成立。

若建議Box–Cox，先取得探索同意，再展示圖形、lambda估計值與95%profile信賴區間。使用者可指定轉換的lambda；同意轉換且未另指定時，採估計值。報告分開記錄估計值與實際使用值。

Box–Cox要求Y為正值。轉換後重新配適及診斷，沿用原X的階數與中心值；不同反應尺度的R²或未校正AIC不直接作優劣比較。

### 5. 檢查離群與影響樣本

最後詢問是否進行離群與影響分析。計算涵蓋全部分析樣本，但輸出僅列至少一項門檻被標記的樣本，包含原始row ID、診斷值、觸發原因與對應DFBETAS。

沒有任何標記時，明確顯示「沒有被所用門檻標記的離群值或影響樣本」。高槓桿、反應離群與影響點分開解釋，不自動刪除資料。

### 6. 結束分析與製作報告

互動期間展示各階段結果與圖形，保存設定及確認紀錄。流程結束後，先告知「此次分析結束」，再生成QMD並編譯PDF，不另詢問是否製作報告。

最終報告只包含實際成功完成的分析；拒絕、未執行、失敗或中止的部分，其標題、程式碼、圖形與說明均不納入。報告逐段依「程式碼 → 實際結果／圖 → 中文解釋」排列。

各確認點均等待明確回答。資料、變數、公式或階數變動後，需重新確認後續分析；尚未回答時不自行結束流程。

## 報告環境與執行設定

報告編譯需要R、Quarto、可用的PDF引擎及中文字型。R套件包括 `MASS`、`lmtest`、`knitr`、`rmarkdown` 與 `yaml`。模板使用XeLaTeX與Microsoft JhengHei；換作業系統時，需調整為當地可用的UTF-8語系及中文字型。

變數角色、模型與各階段的確認狀態分開保存。多項式以名稱指定階數，例如 `polynomial_degrees: {Girth: 2}`；`boxcox_lambda: null`表示使用估計值，填入數值則使用指定值。授權參數不代表該步已成功完成，報告另以 `completed_stages` 決定實際章節。

流程結束後，由執行端使用當次設定生成報告：

```r
source("<skill路徑>/scripts/finalize_report.R", encoding="UTF-8")
write_final_report(
  template="<skill路徑>/assets/report.qmd",
  output="report/analysis.qmd",
  params=analysis_params,
  completed_stages=completed_stages,
  analysis_finished=TRUE,
  render=TRUE
)
```

`analysis_params`保存資料路徑、Y、X、模型階數、中心值、lambda及確認設定。`completed_stages`可包含 `exploration`、`vif`、`fit`、`diagnostics`、`boxcox_profile`、`boxcox`、`influence`，只記錄成功完成的步驟。例如僅完成模型配適時，使用 `c("exploration","vif","fit")`。

交付內容為QMD、編譯且檢視過的PDF，以及重現所需的CSV與R程式。若編譯失敗，保留QMD與R輸出，說明錯誤，不宣稱PDF已完成。

## 可重現性與解讀原則

`configure()`固定種子20261020、亂數產生方式、數字顯示與contrasts。另保存資料MD5、row次序、缺失處理、factor levels、參考組、模型公式、階數、中心值、VIF基底、alpha及lambda設定，並記錄 `sessionInfo()` 與Quarto版本。

OLS本身沒有隨機性；數值重現仍需相同資料、設定及軟體環境，跨機使用時可用renv鎖定套件。PDF的字型、時間及metadata可能不同，因此不保證檔案位元組一致。

預設採alpha＝0.05、雙尾檢定與95%信賴區間。結論依實際R輸出撰寫，關聯不等於因果，R²不代表外部預測準確率，診斷門檻也不代表自動刪除規則。

## 方法依據

主要方法參考 `Program_1.pdf`、`Program_2.pdf`，以及Montgomery、Peck與Vining（2012）的 *Introduction to Linear Regression Analysis* 第5版。VIF、多項式基底與相關補充方法的來源，連同章節對照及教材勘誤，整理於 `references/methods.md`。原始參考PDF不隨skill資料夾附送。
